## Introduction

Dynamic document generation is a common feature in enterprise and simulation applications. Producing downloadable PDF receipts or account statements requires server-side rendering tools capable of formatting text layouts, graphics, and embedded images.

In **Gringotts Wizarding Bank**—a **portfolio and educational banking simulation**—PDF statement downloads and verification QR codes are dynamically generated using **PDFKit** and **QRCode** in Node.js.

## Project Context

To enhance the realism of the Gringotts Wizarding Bank educational simulation, users can request downloadable account statements for their simulated transactions. Each PDF features custom layout formatting and an embedded QR code linking to a verification signature.

## Implementation Details

### Generating QR Code Data URIs

The backend converts payload data into a Data URL image buffer before rendering into the PDF document:

```typescript
import QRCode from 'qrcode';
import PDFDocument from 'pdfkit';

export async function generateStatementPDF(accountNumber: string, transactions: any[]): Promise<Buffer> {
  const doc = new PDFDocument({ margin: 50 });
  const buffers: Buffer[] = [];

  doc.on('data', buffers.push.bind(buffers));

  // Render Header
  doc.fontSize(20).text('Gringotts Wizarding Bank - Account Statement', { align: 'center' });
  doc.moveDown();
  doc.fontSize(12).text(`Account Number: ${accountNumber}`);
  doc.text(`Generated Date: ${new Date().toLocaleDateString()}`);
  doc.moveDown();

  // Generate Verification QR Code
  const qrDataUrl = await QRCode.toDataURL(`VERIFY:${accountNumber}:${Date.now()}`);
  
  // Embed QR Code Image into PDF
  doc.image(qrDataUrl, {
    fit: [100, 100],
    align: 'right',
  });

  doc.end();

  return new Promise((resolve) => {
    doc.on('end', () => {
      resolve(Buffer.concat(buffers));
    });
  });
}
```

## Disclaimer

Gringotts Wizarding Bank is an educational portfolio banking simulation. Statements generated by this system are purely simulated and have no real financial value.
